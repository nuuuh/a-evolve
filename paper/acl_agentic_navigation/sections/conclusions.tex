\section{Conclusions}
\label{sec:conclusions}

Existing auto-harness systems neither improve their construction capability over time nor adapt to each incoming task. We address both gaps: a stateful multi-agent evolver accumulates cross-cycle knowledge to build increasingly rich harnesses, and a strategy-tree navigator routes each task to the best-suited harness branch at solve time. On three long-running streams the system outperforms all baselines and is the only one whose capability compounds rather than degrades over the stream.
