\section{Related Work}
\label{sec:related}

\noindent\textbf{Continual learning and non-stationarity.}
A long line of work in machine learning addresses the failure of monolithic models under distribution drift. \emph{Continual learning} retains prior knowledge across changing tasks~\cite{kirkpatrick2017ewc,delange2021cl}; \emph{domain adaptation} aligns source and target distributions~\cite{ben-david2010da,ganin2016dann}; and \emph{test-time adaptation} updates the deployed model online from each batch~\cite{wang2021tent,liang2020shot}. Mixture-of-experts methods take a complementary route, dispatching each input to a specialised sub-model rather than asking one model to fit all~\cite{jacobs1991moe,shazeer2017moe}. All four operate on model weights. We adapt these intuitions to LLM agents at the \emph{harness} level (prompts, skills, tools, infrastructure), where weight updates are unavailable but harness mutations and per-task selection are.

\noindent\textbf{Self-improving and self-evolving agents.}
The closest LLM-agent precedents to our setting are systems that update the harness directly from execution feedback. A-Evolve~\cite{aevolve} introduces a linear-chain evolver: each cycle reads batch trajectories and mutates prompts, skills, memory, and tools. GEPA~\cite{gepa2025} adds reflective Pareto prompt evolution using textual feedback rather than scalar reward. Meta-Harness~\cite{metaharness2026} uses a growing filesystem archive and Claude Code as the proposer. Continual Harness~\cite{continualharness2025} enables online adaptation within a single continuous deployment run through alternating action/refinement cycles. SkillOS~\cite{skillos2025} learns a skill curation policy via reinforcement learning, training a curator to select and refine reusable skills from repeated interactions. Our work differs from all of these in two respects: (i) we employ a multi-agent evolver that explores competing improvement strategies in parallel rather than a single-agent linear chain or learned curator, and (ii) we introduce a strategy-tree navigator that performs per-task harness selection at solve time, addressing the adaptation loss that prior systems leave untouched.
